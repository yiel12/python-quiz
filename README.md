# python 콘솔 퀴즈 개발
python console quiz game project
## 1. 프로젝트 개요
Python 기본 문법과 객체지향 프로그래밍을 활용하여 터미널에서 실행하는 퀴즈 게임을 개발합니다. Git과 Github를 사용하여 기능별 변경 이력을 기록하고 협업합니다.

## 2. 퀴즈 주제 및 선정 이유
-**퀴즈 주제:** Python 기초 문법
-**선정 이유:** 입학연수에서 학습한 변수, 조건문, 번복문, 함수, 클래스 등 Python 기초 개념을 복습하기 위해 선정했습니다.
-**문항 수:** 5문항 이상 (각 문항은 문제, 선택지 4개, 정답 포함)

>퀴즈 주제와 선정 이유는 실습 예시입니다. 실제 팀 프로젝트에서는 자유롭게 수정할 수 있습니다.
